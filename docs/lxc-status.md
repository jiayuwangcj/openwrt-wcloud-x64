# OpenWrt LXC：已放弃

决定日期：2026-10-25。

## 决定与依据

停止推进本工程的 OpenWrt LXC 部署、适配及性能优化，家用路由继续使用
虚拟机。依据用户此前的实际测试，LXC 相比虚拟机性能提升不超过 10%，
家用场景没有明显体验差异；本次未重新进行性能测试。

LXC 共用宿主机内核，内核故障可能影响 pve2 上所有虚拟机和容器，
包括生产 wrt2。现有旧 CT 200 还是特权容器，配置了 TUN/PPP 设备访问
及宿主机启动 hook。相较于这部分有限性能收益，优先保留虚拟机的内核
隔离边界。虚拟机也不代表绝对隔离，但客户机内核 panic 通常局限于客户机。

## 只读检查留档

- pve2 承载生产 wrt2：VM 102 正在运行，旧 LXC CT 200 已停止。
- 两份旧模板及 CT 200 均为 OpenWrt 22.03.0；现存模板根目录和启动文件
  基本正常，磁盘文件系统标记为 clean。没有找到足以定位原始异常的日志。
- 旧容器模块版本为 5.10.138，宿主内核为 5.15.60-1-pve。容器需要使用
  宿主内核的功能与模块，不能直接加载固件自带的不匹配内核模块。
- CT 200 的 WAN 配置为 vmbr0/VLAN 5，与当前 VM 102 的 vmbr1 不同。
  历史网络配置不应直接复用到当前生产环境。

此次仅作只读检查，未修改 pve2、加载模块、挂载磁盘或启停容器。
停止推进不包含删除宿主机上的旧 CT、模板或磁盘；pve2 的所有写操作
仍须另行授权。

## 工程维护范围

README 中的旧 LXC 命令及 `pve/200.conf` 仅作为历史记录保留。
后续不再安排 LXC 启动复现、专用镜像打包或宿主机适配。
现有通用 rootfs tar 产物继续保留，不代表提供受维护的 LXC 部署方案。
当前维护重点为 x86_64 虚拟机镜像、固件构建校验及虚拟机升级验证。
